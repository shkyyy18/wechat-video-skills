# 微存 WeSave · macOS 微信视频保存

## 平台路由

微信视频号是主入口，走下列下载/录制流程。抖音链接或明确“下载抖音”时，先读 [抖音获取](references/douyin.md)，使用授权浏览器取得当前作品媒体，再运行 scripts/douyin.py。不要把抖音链接交给微信 download.py；不用 OBS 冒充原文件下载。

## 微信执行顺序

1. 确认系统匹配本包。沿用用户已给的视频链接、保存目录和范围，不重新做账号发现。
2. 阅读 references/setup.md。需要 Python 3.10+、FFmpeg/ffprobe 和用户已配置的本机 wx_channels_download v260907。当前为开发预览，真实微信下载尚待该系统验收。
3. 仅保存用户授权的内容。不能把分享链接当作已登录、可访问、可下载的证据。不自动安装证书、改代理、禁用系统保护或处理访问绕过。
4. 从本 Skill 文件夹运行 scripts/download.py，传入 --url 和绝对 --out-dir。只使用数值回环 API。成功创建后记录 task_id；不把 HTTP 200 当成功。
5. 超时或中断后按 task_id 使用 --resume-id 续查。创建响应丢失时先查看上游任务列表，禁止盲目重试创建。
6. 完成须核对实际本地文件、时长、音轨、解码与 SHA256。保留原文件；只有要求裁切时才生成新的副本。没有音轨必须说明，不能声称原声保留。
7. 给用户可点击的本地文件、明确下载或录制模式及技术检查结果。音轨存在不等于实际听过；没有连续播放/听检不能声称完整观感或声画同步验收。

## 输出与限制

输出 task_id、mode、文件绝对路径、时长秒数、画面尺寸、音轨数量、SHA256、技术检查与用户验收状态。遇到无效链接、业务错误、未知状态、路径越界、缺文件或解码错误即停止并说明具体下一步。日志保留本地，不自动上传；不要把私人链接、账号或密码写入 Skill。

本包不含下载器二进制，不保证任意微信视频兼容，不自动发布。完整 CLI 参数：scripts/download.py --help。依赖和许可见 references/dependencies.md。

## macOS 边界

不运行 Windows OBS 脚本，不复用不完整的旧 .command 安装包。不声称 Apple Silicon 或 Intel 真机通过，直到有真实验收记录。
