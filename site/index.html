按系统选择 Skill，自动提交下载任务、等待结果、检查文件；Windows 还提供 OBS 定时录制备用流程。

macOS

本机下载 API → 任务续查 → 视频核验

需要已配置的上游运行时；Mac 真机下载待验收。

Windows

本机下载 API ＋ OBS 定时录制 → MP4

下载待真机验收；OBS 副本是重新编码的播放记录。

一句指令，明确结果

“把这个视频号链接保存到指定目录，检查能否播放，并告诉我是下载原文件还是录制副本。”

这是使用方式示例，不是已执行任务或真实用户反馈。Skill 不代替微信登录、访问权限、应用准备或实际听检。

透明的能力边界

下载引擎来自独立上游项目，录制来自 OBS，媒体处理来自 FFmpeg；本项目提供流程协调、错误处理和交付检查。
