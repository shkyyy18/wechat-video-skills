本报告是本地证据清单，不是 Glama 或第三方颁发的评级。检查方式沿用成熟工具项目的契约、描述、测试、发布和外部复核原则；Skill 不是 MCP Server，因此不存在可直接继承的 MCP 工具定义总分。

| 接口与运行状态契约 | 已实现并合成验证 | 固定上游版本、真实本机 HTTP 测试、嵌套错误和逐项错误 |
