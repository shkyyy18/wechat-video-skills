# Contributing

Keep runtime dependencies minimal and OS packages self-contained. Edit shared scripts in src/, then run python tools/build.py to synchronize packaged scripts. Run Python/Node tests and review docs for claims matching evidence.

Use synthetic fixtures only. Do not add credentials, runtime binaries, certificates, browser profiles, actual share links, private media or machine paths. Real-device validation may be reported as a redacted compatibility result; do not imply one device covers all versions.

Promotion submissions must identify the preview status and upstream dependency. Directory submission, publication, adoption and payment are separate outcomes.
